## Implemented behavior

- ACC can select **Automatic**, **ChatGPT Remote**, or a configured coordinator-capable direct agent such as Claude or DeepSeek.
- Automatic routing ranks eligible agents using task fit, required capabilities, quality, reliability, cost, continuity, and recorded outcomes.
- TypeSafe Jev can contribute a typed `Choice` probability distribution when configured. Deterministic policy remains authoritative and works without TypeSafe credentials.
- User tasks do not pause for assignment approval. The selected orchestrator decomposes requested work and routes it through ACC's existing execution/review controls.
- Planner success, failure, duration, reported cost/usage, and replacement frequency update coordinator routing profiles.
- A failed planner can move to another eligible coordinator and then the configured local fallback.
- Each orchestrator session has a separate ACC transcript. The shared task ledger and a bounded handoff checkpoint carry relevant continuity across a switch.
- An idle switch is immediate. An external lease is fenced immediately. A direct supervised turn switches at its safe process boundary.
- Pending messages follow an intentional switch; handled messages remain in their original transcript.
- Browser text, saved drafts, IndexedDB outbox items, recordings, transcription results, HTTP history, and MCP reads/sends retain their session identity.
- Stale saved direct-session selections recover to Automatic rather than blocking startup.

## Known issues and unverified boundaries

1. `test_deepastra_adapter.DeepAstraOrphanCleanupTests.test_kill_orphans_reaches_a_detached_grandchild` still fails in this Linux container because a detached fixture grandchild writes one more heartbeat after cleanup. This predates and is outside the orchestrator/session changes.
2. One earlier full-suite run also reported an unconfirmed runner termination during `test_job_backed_workflow`; the test passed immediately in isolation and did not recur on the final full run.
3. No live TypeSafe Jev request was made because `TYPESAFE_API_KEY` was unavailable. The typed integration and deterministic fallback are covered with test doubles.
4. Native ChatGPT desktop/Remote, real Claude/DeepSeek provider sessions, browser clicking, microphone capture, and native Windows behavior were not available in this container and remain host validation tasks.
5. ACC cannot wake an idle native ChatGPT conversation. If ChatGPT Remote is selected without a live external lease, configured backup routing may handle text entered in ACC; the active owner remains visible.
6. Full takeover while the desktop host is completely offline still requires ACC state and the repository on an always-on or cloud host.
